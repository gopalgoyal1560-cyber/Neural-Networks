## Model 1: MLP from Scratch (NumPy), `second.py`

- Fully connected MLP with configurable hidden layers and neurons
- He weight initialization
- ReLU activation, Softmax output layer, Cross-Entropy loss
- Manual forward propagation and backpropagation
- Mini-batch gradient descent
- Training loss and test accuracy plots

## Model 2: MLP with PyTorch, `third.py`

- Dynamic MLP architecture (user-defined layers and neurons per layer)
- ReLU activation with Dropout (p = 0.2)
- `CrossEntropyLoss` and Adam optimizer (lr = 0.01)
- Mini-batch training with `DataLoader` (batch size 32), 10 epochs
- Validation accuracy tracking
- Saves weights with `torch.save(model.state_dict(), "model.pth")`
- Training loss and validation accuracy plots

**Dataset (Models 1 and 2):** MNIST handwritten digits via `fetch_openml('mnist_784')`. Images are 28 x 28 grayscale, flattened to 784 values and standardized. `third.py` splits the data into 40,000 train / 20,000 validation / 10,000 test.

**Example architecture:** 3 layers with 128 and 64 hidden neurons:

```
784 (input) -> 128 (ReLU + Dropout) -> 64 (ReLU + Dropout) -> 10 (output)
```

## Deployment

### Backend on Render
1. Create a **New > Web Service** and connect this repository.
2. **Root directory:** `backend` (TODO: match your repo)
3. **Build command:** `pip install -r requirements.txt`
4. **Start command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. Make sure the trained weight files are available to the service, then deploy.

### Frontend on Streamlit Community Cloud
1. Create a new app at [share.streamlit.io](https://share.streamlit.io) from this repo, main file `app.py`.
2. Under **Settings > Secrets** add:
   ```toml
   BACKEND_URL = "https://YOUR-BACKEND-NAME.onrender.com"
   ```
3. Deploy.

## Tech Stack

NumPy, PyTorch, scikit-learn, matplotlib, Streamlit, a Python web API (FastAPI/Flask) on Render.

## Learning Objectives

- Matrix-based forward propagation, backpropagation and gradient computation
- Weight initialization, activation functions and Cross-Entropy loss
- Mini-batch gradient descent and Adam
- Self-attention, causal masking and the transformer decoder architecture
- Serving trained models through an API and deploying a full-stack ML app
